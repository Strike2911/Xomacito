# Xomacito 1.4.0 — Modo rápido, Biblioteca y Premiere

- Modo rápido con búsqueda paginada, caché temporal y miniaturas ligeras. Las búsquedas anteriores no reemplazan los resultados nuevos.
- Biblioteca con paneles ajustables, previsualización de video y audio, metadatos, colecciones y selección múltiple.
- Estudio con mayor espacio para la imagen, nuevos iconos y controles de salida reorganizados.
- Xomacito Link 1.6: panel compacto, explorador bajo demanda, envíos por lotes, autoimportación al terminar y envío de selecciones de Premiere hacia Xomacito.
- Opción para insertar nuevas descargas en V1/A1 y controlar la inclusión de imágenes.
- Configuración simplificada: se retira el apartado Consola.

Actualización ligera para instalaciones existentes de Xomacito en Windows. Conserva cuenta, colección, saldo y preferencias.

Después de actualizar, instala **Xomacito-Link.ccx** desde Biblioteca > Conectar Premiere y reinicia Premiere. La conexión requiere vincular la misma carpeta de Biblioteca y mantener el panel abierto. La inserción al cabezal desplaza los clips siguientes.

Versión interna: 4.0.40. La integración utiliza las API de Premiere 25.6 o posterior; las pruebas automatizadas del puente usan un host simulado. El renderizado y las importaciones de esta versión aún requieren comprobación final en Premiere.
