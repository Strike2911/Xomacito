# Xomacito 1.0 Definitive Edition

The Definitive Edition consolidates downloads, the queue, Image Studio, the cat collection, and community tools in one release.

## Compatible automatic update

The public label is **Xomacito 1.0 Definitive Edition**. The installer uses the internal revision `4.0.0`, which is newer than the 3.x installations, so Windows and Xomacito's updater accept the replacement automatically.

Older releases stay published. The updater reads the latest published release, so preserving the history does not create an update conflict.
