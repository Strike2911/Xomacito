# Xomacito 2.9 — ¡LA EDUARDITO UPDATE!!

La cola deja de ser una caja negra: ahora permite revisar las canciones y videos detectados dentro de una playlist, elegir cuáles se procesan y confirmar su destino antes de iniciar.

## Novedades

- Previsualización visible y seleccionable de todos los elementos de una playlist.
- Acciones rápidas para seleccionar todo o vaciar la selección.
- Modo y calidad independientes por cada playlist.
- Etiquetas con color y carpeta compartidas entre Descargar y Cola.
- Opciones avanzadas plegables para reducir la carga visual sin eliminar herramientas.
- Carpeta efectiva y etiqueta visibles antes de iniciar la cola.
