# Xomacito 2.7 — ¡LA BLACKBULL PLAYLIST UPDATE!!

Esta versión corrige el caso en el que una playlist aparecía como completada aunque
su carpeta de salida estuviera vacía.

## Correcciones

- Recupera la URL completa desde entradas planas de YouTube y Vimeo.
- Valida que cada elemento haya producido un archivo multimedia real.
- Distingue entre éxito total, resultado parcial y fallo total.
- Conserva mensajes útiles para reintentar elementos fallidos.
- Elimina una carpeta de playlist vacía cuando ningún elemento pudo descargarse.
