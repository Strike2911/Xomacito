# Xomacito 1.3.0 — ALL MY FELLAS!!

- Nueva colección Noche de Entierro: 67 gatos disponibles y Gato Hola como secreto de Halloween.
- Xomas, Megas y Spike protagonizan la portada, con animaciones propias. Spike ahora tiene seis estrellas.
- Gato Mago y Black Bull se incorporan a la caja 2. Se trasladan 8 comunes y 4 raros desde OG, conservando las probabilidades por rareza.
- Perro Zane puede salir en la caja OG. Gato Xomacito pasa a llamarse Gato Follador.
- Hola aparece en la primera apertura válida de octubre de 2026 tras actualizar, incluida la gratuita. Su sonido se reproduce al revelarse.
- Se conservan los gatos obtenidos, saldo y progreso. Nini se suma a los contribuyentes.

## Instalación

Windows: Setup para instalar desde cero; Update-Light para actualizar una instalación existente. macOS: DMG para Apple Silicon (arm64), requiere macOS 26.0 o posterior.

La versión interna 4.0.30 permite actualizar correctamente desde las versiones históricas 3.x y 4.x; la versión visible es 1.3.0.
