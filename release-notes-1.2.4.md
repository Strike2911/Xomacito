# Xomacito 1.2.4 — Upscayl y estado de dependencias

Solo actualización ligera para instalaciones existentes. Conserva modelos, preferencias, gatos, saldo y descargas.

- Nuevo acceso a Instalar/Reparar Upscayl en Configuración > Dependencias. Corrige las instrucciones del reescalador de video que apuntaban a una sección antigua.
- Descarga del motor y modelos con hasta tres intentos, detección de transferencias incompletas y validación del ZIP. Un paquete sin ejecutable no se anuncia como instalado. Se conservan los modelos personalizados al fusionar archivos.
- Dependencias distingue Actualizado, Actualización disponible y versión sin comprobar. Los botones antes vacíos ahora muestran Instalar, Actualizar o Reinstalar.
- Estudio elimina la barra horizontal blanca y reserva espacio para el desplazamiento vertical. Los controles usan una base compatible con el tema personalizado, también en Windows.

Para preparar el escalador: Configuración > Dependencias > Upscayl > Instalar. El motor y sus modelos se descargan por separado solo cuando faltan; no se incluyen en este instalador ligero.

Validación: instalación real de Upscayl desde una carpeta vacía, descarga de sus tres modelos esenciales y ejecución real de una mejora 32×32 a 64×64. Pruebas de reintentos, preservación de modelos, comparación de versiones y carga visual de Estudio/Dependencias.

La captura reportada muestra actualizaciones disponibles para FFmpeg (8.0.1 → 9.0.1), Deno (2.7.13 → 2.9.6) y Poppler (25.12.0-0 → 26.07.0-0). yt-dlp 2026.08.19 coincide con la última versión consultada. Buscar actualizaciones consulta las versiones sin instalarlas automáticamente.
