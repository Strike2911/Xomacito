# Xomacito 1.2.9 — YouTube y gatitos de descarga

Actualización ligera para Windows con Xomacito ya instalado. Conserva los componentes, modelos y preferencias existentes.

- Corrige el aviso incorrecto «Video unavailable» en videos públicos que el reproductor incrustado de YouTube no permite analizar. Se realiza un único reintento con los clientes predeterminados de yt-dlp.
- El reintento conserva el formato, la calidad seleccionada, el destino y las cookies configuradas. También se aplica a descargas y vistas previas.
- Retira el gato siamés de Personalización. Quedan el clásico y el naranja; una selección anterior del siamés cambia automáticamente al clásico. El instalador elimina sus dos imágenes antiguas.
- Conserva los cambios recientes de soporte de macOS en el código fuente; el instalador adjunto es exclusivamente para Windows.

Se verificó el enlace https://youtu.be/863rTle6CKY mediante el análisis de la app y una descarga completa: video 1920×1080 con audio, duración de 31,588 segundos.

Para una instalación nueva, instala primero el [instalador completo de Xomacito 1.2](https://github.com/Strike2911/Xomacito/releases/download/v4.0.19/Xomacito-1.2-Setup.exe) y después esta actualización ligera.
